# Changelog

Notable changes to Zarf are documented here.

## [1.2.0] - 2026-11-20

### Added

- Persistent English and Arabic language selection in the Flutter mobile app.
- Arabic translations and right-to-left layout across mobile workflows, with locale-aware dates and number formatting.

### Improved

- Android splash screen now uses a dedicated transparent logo asset for clearer display.

### Changed

- Bumped the mobile app version to `1.2.0+6`.
